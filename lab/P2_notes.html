Database Fundamentals and Data Extraction with Python

These notes support Practical 2. The practical uses the supplied college.db; students do not create the database.

1. What Is a Database?

A database is an organized collection of data designed for storage, management, search and retrieval.

2. Relational Databases

Relational databases organize related data into tables. Rows are records; columns are fields or attributes.

3. The Database for This Practical

college.db contains the students table. It has id, name, department and marks. It is already prepared.

4. SQL

SQL means Structured Query Language. SELECT retrieves data.

SELECT * FROM students;

5. Selecting Columns

SELECT name, marks
FROM students;

6. Filtering with WHERE

SELECT * FROM students
WHERE marks > 80;

7. Sorting with ORDER BY

SELECT name, marks
FROM students
ORDER BY marks DESC;

8. SQLite

SQLite is a lightweight relational database engine that stores the database in a file. Python provides the sqlite3 module.

9. Connecting Python

import sqlite3
conn = sqlite3.connect("college.db")
cursor = conn.cursor()

10. Executing and Fetching

cursor.execute("SELECT * FROM students")
rows = cursor.fetchall()

The cursor executes SQL; fetchall() retrieves all returned rows.

11. Displaying Results

for row in rows:
    print(row)

12. Closing the Connection

conn.close()

13. Complete Mental Model

Python → Connect → SQL Query → Database → Result → Python

14. Primary Key

A primary key uniquely identifies a record. In this database, id is the primary key.

15. Schema

A schema describes the structure of a database, including tables, columns and constraints.

16. Important Terms

TermMeaning

Column/FieldOne attribute.

17. Parameterized Queries

When values come from external input, parameterized queries are safer than string concatenation.

cursor.execute(
    "SELECT * FROM students WHERE department = ?",
    ("CSE",)
)
