Bayes’ Rule in Python: Probability of Student Absence Given That Today Is Friday

Syllabus-aligned practical

Syllabus task: The first practical asks students to calculate the probability that a student is absent given that today is Friday, using Bayes’ rule in Python. The syllabus gives the expected answer as 15%.

Lab time: 4 practical hours/week are allocated in the syllabus. This manual is specifically for Practical 1.

1. Learning Objectives

Understand

Recognize conditional probability and the quantities needed for Bayes’ rule.

Calculate

Compute a conditional probability from the values supplied in the problem.

Implement

Translate the mathematical formula into a short Python program.

Interpret

Explain why the answer is 15%, rather than simply reporting a number.

2. Problem Statement

The probability that it is Friday and that a student is absent is 3%.

There are 5 school days in a week, so the probability that it is Friday is 20%.

Find: the probability that a student is absent given that today is Friday, and apply Bayes’ rule in Python.

3. Given Information

SymbolMeaningValue
P(F)Probability that today is Friday0.20
P(A ∩ F)Probability that it is Friday and the student is absent0.03
P(A | F)Probability of absence given that today is FridayTo calculate

4. Theory: What We Need

Conditional probability: P(A | F) means “the probability of A when we already know F has happened.”

For this practical, we can use the conditional-probability form of Bayes’ rule:

P(A | F) = P(A ∩ F) / P(F)

Substitute the given values:

P(A | F) = 0.03 / 0.20 = 0.15 = 15%

5. Step-by-Step Procedure

  1. Open Python, Google Colab, Jupyter Notebook, or another Python environment.
  2. Create variables for the joint probability and the probability of Friday.
  3. Divide the joint probability by the probability of Friday.
  4. Store the result in a variable.
  5. Convert the result to a percentage by multiplying by 100.
  6. Print both the decimal probability and percentage.
  7. Check that the program produces the syllabus answer: 15%.
  8. Write a short interpretation in your practical record.

6. Python Implementation

prob_friday_and_absent = 0.03
prob_friday = 0.20

prob_absent_given_friday = prob_friday_and_absent / prob_friday
percentage = prob_absent_given_friday * 100

print("P(Absent | Friday) =", prob_absent_given_friday)
print("Probability =", percentage, "%")

7. Expected Output

P(Absent | Friday) = 0.15
Probability = 15.0 %
Interpretation: Given that today is Friday, the probability that the student is absent is 15%.

9. Common Mistakes

  • Entering 3 instead of 0.03 for 3%.
  • Entering 20 instead of 0.20 for 20%.
  • Dividing by the wrong probability.
  • Confusing P(A | F) with P(F | A). They are generally not the same.
  • Reporting 0.15 as “0.15%”. It is 15%.

11. Viva Questions: Core Concepts

These questions test the concepts needed to understand and extend the practical, rather than asking students only to repeat the code.

QuestionWhat a good answer should cover
What is probability?A numerical measure of how likely an event is, usually between 0 and 1.
What is conditional probability?The probability of an event when another event is already known to have occurred.
What does P(A | F) mean?The probability of A given F.
What does P(A ∩ F) mean?The probability that A and F occur together.
State Bayes’ theorem.P(A | B) = [P(B | A) × P(A)] / P(B), provided P(B) > 0.
How is P(A ∩ F) related to conditional probability?P(A ∩ F) = P(F | A) × P(A) and also P(A ∩ F) = P(A | F) × P(F).
Why is P(A | F) not generally equal to P(F | A)?The condition is different; conditional probabilities are generally not symmetric.
What is the difference between joint and conditional probability?Joint probability concerns both events occurring; conditional probability concerns one event within the cases where another is known.
Why can probability be written as 0.15 or 15%?They represent the same probability; 15% = 15/100 = 0.15.
What is the role of the denominator in P(A | F)?It represents the probability of the condition F and normalizes the joint probability to the Friday cases.
What information is required to calculate P(F | A) from P(A ∩ F)?P(A) is required, because P(F | A) = P(A ∩ F) / P(A).
Can P(F | A) be calculated from the two values given in this practical alone?No. We know P(A ∩ F) = 0.03 and P(F) = 0.20, but P(A) has not been supplied.

🗝️ Lab Exercise: Is P(A | F) the Same as P(F | A)?

Task: Determine whether P(A | F) is the same as P(F | A).

Submission: Show your formulas, calculations, and a short written conclusion. Do not submit only a final number.

🔐 Treasure Unlocked: Reference Solution

1. Calculate P(A | F)

P(A | F) = P(A ∩ F) / P(F)

= 0.03 / 0.20 = 0.15 = 15%

2. Write P(F | A)

P(F | A) = P(A ∩ F) / P(A)

3. Can we calculate P(F | A) numerically?

No. The practical gives P(A ∩ F) = 0.03, but it does not give P(A). Therefore:

P(F | A) = 0.03 / P(A)

4. Are the two probabilities necessarily equal?

No. In general, P(A | F) ≠ P(F | A) because they condition on different events.

5. Bayes' theorem connection

P(A | F) = [P(F | A) × P(A)] / P(F)

The joint-probability identity behind this is:

P(A ∩ F) = P(F | A) × P(A)
Final conclusion: P(A | F) = 15%. A numerical value for P(F | A) cannot be obtained from the supplied data alone because P(A) is missing.
