Probability & Bayes’ Rule — Basics for Practical 1

A simple, intuitive introduction before writing the Python program.

What you need to know for this practical: probability, percentages as decimals, joint probability, conditional probability, Bayes’ rule, and basic Python arithmetic/printing.

1. Probability: The Language of Uncertainty

Probability tells us how likely an event is to happen. It is represented by a number from 0 to 1.

ProbabilityPercentageMeaning
00%Impossible
0.550%One-half chance
1100%Certain

To convert a percentage to a decimal, divide by 100. Therefore, 3% = 0.03 and 20% = 0.20.

2. Events

Let:

  • A = student is absent.
  • F = today is Friday.

An event is simply something we are interested in observing.

3. “AND” Means Joint Probability

P(A ∩ F) means the probability that both events happen: the student is absent and today is Friday.

In the practical, this is given as 3%, so:

P(A ∩ F) = 0.03

4. “Given That” Means Conditional Probability

The notation P(A | F) is read as:

“Probability of A given F.”

Here, we already know that it is Friday. We are asking: among the Friday cases, how likely is absence?

5. The Formula

P(A | F) = P(A ∩ F) / P(F)

This is the conditional-probability form used in the practical. It is also consistent with Bayes’ rule when the joint probability is already available.

6. Apply It to the Friday Example

QuantityValue
P(A ∩ F)0.03
P(F)0.20

Therefore:

0.03 ÷ 0.20 = 0.15
0.15 × 100 = 15%

7. Understanding the Example with Counts

Imagine 100 school days. If 20 of those days are Fridays, and 3 days are both Friday and an absence day, then among the 20 Friday days, 3 involve absence.

So the fraction is:

3 / 20 = 0.15 = 15%
The important idea is that the condition “it is Friday” changes the group we are looking at.

8. Bayes’ Theorem and the Joint-Probability Relationship

Bayes’ theorem lets us reverse the direction of a conditional probability. Its general form is:

P(A | B) = [P(B | A) × P(A)] / P(B)

The key relationship behind Bayes’ theorem is the joint-probability identity:

P(A ∩ F) = P(F | A) × P(A)

It can also be written from the other direction:

P(A ∩ F) = P(A | F) × P(F)

Equating these two expressions gives:

P(F | A) × P(A) = P(A | F) × P(F)

and therefore:

P(A | F) = [P(F | A) × P(A)] / P(F)
Important for this practical: the question directly gives P(A ∩ F) and P(F), so P(A | F) can be calculated as P(A ∩ F) / P(F). However, P(F | A) cannot be given a numerical value unless P(A) is also known.

9. Why P(A | F) and P(F | A) Are Different

P(A | F) asks: “If I already know it is Friday, how likely is absence?”

P(F | A) asks: “If I already know the student is absent, how likely is it that today is Friday?”

These are different questions. In general:

P(A | F) ≠ P(F | A)

For the current data, we know:

  • P(A ∩ F) = 0.03
  • P(F) = 0.20
  • P(A) is not supplied.

So:

P(A | F) = 0.03 / 0.20 = 0.15 = 15%

P(F | A) = 0.03 / P(A)

The second expression is correct, but it cannot be reduced to a number without P(A).

10. Python Basics Needed

You do not need advanced programming. Only four ideas are required.

Variables

Store a value using name = value.

Arithmetic

Use / for division and * for multiplication.

Output

Use print() to display a result.

Comments

Use # to add an explanation that Python does not execute.

# Given probabilities
prob_friday_and_absent = 0.03
prob_friday = 0.20

# Conditional probability
prob_absent_given_friday = prob_friday_and_absent / prob_friday

# Convert to percentage
percentage = prob_absent_given_friday * 100

print(percentage, "%")
