🗝️ Lab Exercise

Task: Using Python, connect to the provided college.db database and extract data from the students table.

Your program should connect, execute an SQL query, fetch the returned data, display it, and close the connection.

Then write queries that:

  • extract only name and marks;
  • extract students whose marks are greater than 80;
  • extract students belonging to CSE;
  • display students in descending order of marks.

Submission: Show your Python program, SQL queries, output, and a short explanation of how Python extracted the data.

8. Viva Questions: Core Concepts

QuestionGood answer should cover
What is a database?An organized collection of data that can be stored, managed and retrieved.
What is a relational database?Related data organized into tables of rows and columns.
What is a row?A single record.
What is a column?A field or attribute.
What is SQL?Structured Query Language for relational databases.
What does SELECT do?Retrieves data.
What does WHERE do?Filters rows.
What does ORDER BY do?Sorts results.
What is SQLite?A lightweight relational database engine stored in a file.
Why use sqlite3.connect()?To connect Python to the SQLite database.
What is a cursor?An object used to execute SQL and work with results.
fetchone vs fetchall?One row versus all remaining returned rows.
Why close the connection?To release resources and end the session.
What is a primary key?A field or fields that uniquely identify a record.
Python vs SQL?SQL specifies the data request; Python manages the interaction and returned data.
Reference solution
import sqlite3

conn = sqlite3.connect("college.db")
cursor = conn.cursor()

cursor.execute("SELECT * FROM students")
rows = cursor.fetchall()

for row in rows:
    print(row)

conn.close()
