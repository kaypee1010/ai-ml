Instructor Guide — Extract Data from a Database Using Python

Syllabus: “Extract the data from database using python.” Students receive college.db; they do not create or populate it.

1. Opening — 3 minutes

Say: “Imagine I give you thousands of student records and ask for only CSE students who scored above 80. Would you search manually? Today we will make Python communicate with a database and retrieve exactly what we ask for.”

2. Explain the Practical — 1 minute

Say: “The database is already prepared. Our task is extraction: connect, ask, receive, and work with the returned data.”

3. Show college.db — 3 minutes

Say: “This SQLite file contains a table called students with id, name, department and marks. A row is one record; a column is one property.”

4. Introduce SQL — 4 minutes

SELECT * FROM students;

Say: “SQL is the language we use to ask a relational database for data. This asks for all columns from students.”

Ask: “If I replace * with name, marks, what will come back?”

5. Python’s Role — 3 minutes

Python → SQL → Database → Result → Python

Say: “Python manages the interaction. SQL describes the request.”

6. Connect — 3 minutes

import sqlite3
conn = sqlite3.connect("college.db")
cursor = conn.cursor()

Say: “Notice that we open an existing database. We are not creating it.”

7. Execute and Fetch — 4 minutes

cursor.execute("SELECT * FROM students")
rows = cursor.fetchall()

Say: “The cursor sends the query; fetchall brings the returned rows into Python.”

8. Display and Close — 3 minutes

for row in rows:
    print(row)

conn.close()

Say: “Now the data is in Python and can be displayed or analyzed. We close the connection when finished.”

9. Ask Better Questions — 5 minutes

Have students predict the result before running:

SELECT name, marks FROM students;

SELECT * FROM students WHERE marks > 80;

SELECT * FROM students WHERE department = 'CSE';

SELECT * FROM students ORDER BY marks DESC;
Say: “The database did not change. We changed the question.”

10. Student Activity — 10+ minutes

Read aloud: “Use the supplied college.db. Connect with Python, extract the student records, display them, and then write additional queries for selected columns, filtering, and sorting. Submit code, queries, output and a short explanation.”

11. Engagement Questions

AskExpected direction
Where is the data stored?Database/table.
What language asks for data?SQL.
What does Python do?Connects, sends query, receives and processes results.
What does WHERE do?Filters rows.
What does ORDER BY do?Sorts results.
Why fetchall?Retrieve all returned rows.

12. Closing — 2 minutes

Say: “Remember: connect, execute, fetch, process or display, close. This simple workflow is the foundation for using Python with databases and for bringing stored data into analysis and machine learning.”

13. Viva Prompts

  • What is a database?
  • What is a relational database?
  • What is a table, row and column?
  • What is SQL?
  • What do SELECT, WHERE and ORDER BY do?
  • What is SQLite?
  • Why use sqlite3.connect?
  • What is a cursor?
  • fetchone versus fetchall?
  • Why close the connection?
  • What is a primary key?
  • SQL versus Python in this practical?

14. Instructor Emphasis

Keep the focus on extraction. Students are given college.db. Database creation is not part of the student task.
